# 网文书城前端设计规范（星辰书城）

本项目是网文书城（起点/番茄模式）课设：React + FastAPI + PostgreSQL + Redis。
UI 目标是：**简约、安静、让读者忘记界面本身**——一切设计服从"连续阅读"这个核心场景。

## 0. 设计基调（先读这条）

- 风格：克制极简（refined minimalism）。不搞渐变色块、不搞霓虹、不搞夸张动效。
- 核心原则：**界面是书的容器，不是展品**。读者 80% 的时间在阅读页，所有页面的视觉噪声必须低于阅读页。
- 一个强调色（如墨绿/靛蓝 #2F5D8C 类）+ 黑白灰阶。封面图是页面里唯一的"彩色"来源。
- 圆角克制（4-8px），阴影只用极淡的投影，边框用 1px hairline（#E8E6E1 类）。
- 响应式优先移动端（番茄/起点读者大量在手机上阅读），桌面端居中限宽。

## 1. 阅读排版规范（最重要，人类阅读习惯）

阅读页是产品的灵魂，排版标准如下：

| 属性 | 值 | 说明 |
|------|-----|------|
| 正文字号 | 16-18px（移动端 17px 最佳） | 不小于 15px |
| 行高 | 1.8 ~ 2.0 | **中文阅读行高必须 ≥1.8**，否则换行黏连 |
| 行长 | 每行 30-40 个汉字 | 容器宽约 620-720px，超长行阅读疲劳 |
| 字距 | letter-spacing: 0.05em | 中文略加字距更透气 |
| 段间距 | 段落间 1em 空行 | 用 `<p>` 块级间距，不用 `<br>` |
| 首行缩进 | 2 字符（text-indent: 2em） | 网文标配，模拟纸质书 |
| 正文对齐 | 两端对齐 justify | 避免右侧参差 |
| 章节标题 | 字号 20-22px，居中，上下留白 2em | 与正文区分层级 |

**字体栈（中文阅读首选宋体系）：**
```css
--font-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", SimSun, serif;
--font-sans:  "Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```
- 正文：衬线（宋体）——长时间阅读比黑体更省眼力
- 界面元素（按钮/导航/标签）：黑体
- 数字/英文：tabular-nums 对齐

**阅读模式（必须做两个）：**
- 日间：纸感底色 `#F7F4EC`（不是纯白！），正文 `#333`
- 夜间：`#1B1B1F` 底，正文 `#A6A6AD`（不要纯黑底纯白字，对比过强刺眼）
- 切换按钮放阅读页顶部，用 localStorage 记住偏好

## 2. 页面结构与组件（React）

```
src/
├── api/            # axios 封装（token 注入、401 跳登录）
├── components/     # 通用组件
│   ├── NovelCard/      # 封面+标题+简介，列表/推荐位复用
│   ├── ChapterList/    # 章节目录
│   ├── Reader/         # 阅读器（核心）
│   └── Pagination/
├── pages/
│   ├── Home/       # 首页：推荐位 + 热榜 + 分类入口
│   ├── NovelDetail/# 详情：简介/目录/评分/评论/打赏
│   ├── Reader/     # 阅读页
│   ├── Bookshelf/  # 书架 + 阅读历史
│   ├── Login/ Register/
│   └── Author/     # 作者后台（发布章节）
└── stores/         # 用户态（token/user 持久化）
```

**阅读器交互（起点/番茄的成熟模式）：**
- 顶部：书名 + 章节名 + 目录按钮 + 模式切换
- 底部：上一章 / 进度条 / 下一章
- 正文区点击：呼出/隐藏顶部底部栏（沉浸式阅读）
- 章节末尾：上一章 | 目录 | 下一章 三按钮
- VIP 章节未购买：正文处显示锁图标 + "购买本章（X 书币）"按钮，购买成功直接继续渲染
- 滚动位置：离开页面时记住，回来恢复（sessionStorage）

**首页布局：**
- 顶部导航：Logo | 分类（玄幻/都市/科幻…）| 搜索框 | 书架 | 登录/头像
- 主区：运营推荐位（大封面横条）→ 热门榜（列表式，带排名数字）→ 分类精选（卡片流）
- 卡片信息：封面、书名、作者、简介两行、评分、状态（连载/完结）

**小说详情页：**
- 上部：封面大图 + 书名/作者/分类/状态/字数/评分/收藏数
- 操作：开始阅读（跳最新进度）/ 加入书架 / 打赏 / 投月票
- 中部：Tab 切换：简介 | 目录（带付费章标识🔒/免费标识）| 评论区 | 评分区

## 3. 简约风格细节清单

- 间距系统：4 的倍数（4/8/12/16/24/32/48/64）
- 字号层级：12（辅助）/ 14（次要）/ 16（正文/默认）/ 18（卡片标题）/ 22（页标题）/ 28（大标题）
- 颜色全部走 CSS 变量（design tokens），禁止散落的魔法色值
- 列表分隔用 hairline 线，不用卡片阴影堆叠
- 空状态要有引导文案（"书架空空如也，去发现好书 →"）
- 加载态：骨架屏（Skeleton），不用转圈菊花
- 动效：仅 hover 颜色过渡和页面切换淡入，过渡 150-200ms
- 移动端底部 Tab：首页 / 书架 / 我的

## 4. 技术栈约定

- React 18 + Vite + React Router v6
- 样式：Tailwind CSS（或纯 CSS 变量 + 模块化，二选一保持一致）
- 请求：axios，baseURL `/api`，开发期 Vite proxy → `http://localhost:8000`
- 登录态：token 存 localStorage，axios 拦截器自动带 `Authorization: Bearer`
- 组件库：不引入重型 UI 库，按需手写（保持风格统一且可控）

## 5. 验收标准

- [ ] 阅读页满足第 1 节全部排版参数（行高≥1.8、行长≤40字、缩进2em）
- [ ] 日/夜两种阅读模式可切换且被记住
- [ ] 免费章直接读、VIP 章未购显示购买入口，购买后无缝续读
- [ ] 移动端 375px 宽度无横向滚动、无错位
- [ ] 首页/详情/书架/阅读器视觉统一，强调色唯一
- [ ] 无 JS 报错，构建通过
